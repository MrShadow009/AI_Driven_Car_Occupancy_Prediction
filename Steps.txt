======================================================
STEP-BY-STEP COMMANDS TO RUN THE PROJECT
======================================================

Step 1 — Install System Dependency (macOS only, one-time)
----------------------------------------------------------
  brew install libomp

  Note: XGBoost uses OpenMP for parallel processing. If libomp
  is missing the app will still run with a fallback prediction.


Step 2 — Navigate to the App Folder
------------------------------------
  cd /Users/vamsipodili/Downloads/AI_Driven_Car_Occupancy_Prediction/smart_parking_app


Step 3 — Create the Virtual Environment (one-time setup)
---------------------------------------------------------
  python3 -m venv venv


Step 4 — Activate the Virtual Environment
------------------------------------------
  source venv/bin/activate

  Your terminal prompt will change to show (venv) on the left.
  Run this EVERY TIME you open a new terminal session.


Step 5 — Install Python Dependencies (one-time setup)
------------------------------------------------------
  pip install -r requirements.txt

  This installs: streamlit, pandas, numpy, xgboost,
  scikit-learn, qrcode, Pillow and all other dependencies.


Step 6 — (Optional) Add Google Maps API Key
--------------------------------------------
  Create the file: smart_parking_app/.streamlit/secrets.toml
  Add this line inside it:

    GOOGLE_MAPS_API_KEY = "YOUR_ACTUAL_API_KEY_HERE"

  Without this key the app shows embedded map previews instead.


Step 7 — Launch the App
------------------------
  streamlit run app.py --server.port 8503

  The app will open automatically in your browser at:
    http://localhost:8503

  To run in the background without auto-opening the browser:
    streamlit run app.py --server.port 8503 --server.headless true

======================================================
TROUBLESHOOTING
======================================================

  Q: "ModuleNotFoundError" on startup
  A: Run:  pip install -r requirements.txt

  Q: Port 8503 already in use
  A: Use a different port:  streamlit run app.py --server.port 8504

  Q: Model predictions not working
  A: Ensure models/best_model.pkl and models/feature_cols.pkl exist

  Q: App shows blank page
  A: Hard-refresh the browser with Ctrl+Shift+R (or Cmd+Shift+R on Mac)
